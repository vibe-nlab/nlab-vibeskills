# SPEC: <название проекта>

> Спецификация — источник правды для кода (SDD, AGENTS.md §3). Код, не
> соответствующий этому документу, — ошибка кода, а не повод молча
> поправить спецификацию. Меняется контракт → сначала правится этот файл,
> потом код, обе правки в одном коммите.
>
> Разделы, помеченные `TODO (этап Design)`, заполняются на этапе Design
> (`/nlab:design`). Prep не стартует, пока в файле остаётся хоть один `TODO`.
>
> Этот файл — индекс спецификации. Подробности этап Design выносит в
> соседние файлы папки `spec/`: `schemas.md` (модели вход/выход),
> `tools.md` (контракты инструментов), `agents.md` (схема агентов). Здесь
> тогда остаётся короткая сводка и ссылка.
