# /nlab:project-start — старт проекта по Golden Path NeuroLab

Точка входа в любой новый проект. Скилл проводит короткое Discovery,
фиксирует намерение в `intent.md` и разворачивает обязательный каркас,
после которого проект может подхватить любой другой агент или сотрудник.
Детальные требования снимаются дальше — на макете (`/nlab:prototype`).

Это исполняемая форма двух документов реестра — [`AGENTS.md`](assets/AGENTS.md)
(процесс) и [`project_setup_best_practices.md`](references/project_setup_best_practices.md)
(стек и модели). Скилл читает их с диска при запуске, поэтому правила и
скилл не расходятся: правится документ — меняется поведение.

Первым делом спрашивает, разработчик вы или работаете с ИИ без кода, — и
дальше объясняет всё соответственно. Ответ сохраняется в проект, так что
переспрашивать на следующих этапах не придётся.

Что делает:

- задаёт только недостающее (гипотеза результата, измеримые критерии
  приёмки, что НЕ входит) и пишет `intent.md`;
- разворачивает каркас: `AGENTS.md` (в корне — чтобы агенты подхватывали
  правила сами) и папку `project-docs/` со всем остальным — `intent.md`,
  `NOTES.md`, `EVIDENCE.md`, `feature-list.json`; плюс
  `.gitignore` и `.env.example`;
- закрепляет дефолтный стек: React из темплейта компании, агенты на
  pydantic-ai, LLM только через OpenAI-совместимый API (OpenRouter или гейт
  nlab), модели в Claude Code — проектирование на Fable-5/Opus-5, код
  субагентами на Sonnet-5;
- проверяет доступы: выдан ли git-репозиторий, есть ли ключ LLM — и не
  изобретает обходных путей, если чего-то нет;
- прогоняет enforcement-проверки (секрет-скан, запрет вызова LLM через CLI,
  append-only аудит) и записывает результат в `EVIDENCE.md`;
- собирает `project-docs/PLAN.html` — разбор проекта простым языком: в чём
  суть, что система будет делать, как это работает по шагам, что получится
  на выходе, какие задачи и что нужно от вас. Открывается двойным щелчком,
  показывается заказчику; `/nlab:code-design` потом дополнит его разделом
  «Как устроено внутри»;
- делает первый коммит.

## Установка

Скилл входит в плагин `nlab` — ставится вместе со всем пакетом, отдельно
копировать ничего не нужно. См. [README реестра](../../README.md).

## Использование

1. Откройте Claude Code в пустой папке будущего проекта.
2. Наберите `/nlab:project-start` и опишите, что нужно сделать — своими словами,
   без терминов.
3. Ответьте на вопросы (как поймём, что работает; что точно не входит;
   выдан ли репозиторий).
4. На выходе — заполненный каркас проекта и список оставшихся блокеров.

## Что скилл делать не будет

- **Создавать git-репозиторий.** Репозитории выдаются централизованно:
  напишите [@sanchezgl](https://t.me/sanchezgl) или
  [@KirillBorovkov](https://t.me/KirillBorovkov), передайте свой
  GitHub-никнейм. До этого работа идёт локально, push отложен.
- **Пропускать Discovery.** На просьбу «просто напиши код» минимум —
  одна фраза-гипотеза и один критерий успеха.
- **Вшивать ключи в код.** `BASE_URL` и ключ LLM — только через env.
