## Проверка актуальности скиллов — раз в день

Скиллы приезжают плагином `nlab` из общего реестра и обновляются часто:
устаревшая копия работает по отменённым правилам и молча делает не то.
Обновление ставит **пользователь** — Claude Code не даёт агенту обновлять
плагины самому, поэтому твоя работа здесь: проверить и сказать.

**В начале сессии**, до содержательной работы, выполни (проверка идёт не
чаще раза в сутки — штамп с датой лежит в `~/.claude/.nlab-skills-checked`):

```bash
STAMP=~/.claude/.nlab-skills-checked
MP=~/.claude/plugins/marketplaces/nlab-vibeskills
if [ "$(cat "$STAMP" 2>/dev/null)" != "$(date +%F)" ]; then
  REG=$(git -C "$MP" fetch -q origin 2>/dev/null && git -C "$MP" show origin/main:.claude-plugin/plugin.json 2>/dev/null | python3 -c 'import json,sys;print(json.load(sys.stdin)["version"])' 2>/dev/null)
  CUR=$(python3 -c 'import json,os;p=os.path.expanduser("~/.claude/plugins/installed_plugins.json");d=json.load(open(p))["plugins"].get("nlab@nlab-vibeskills",[]);print(d[0]["version"] if d else "")' 2>/dev/null)
  if [ -n "$REG" ]; then
    [ "$CUR" = "$REG" ] && echo "скиллы nlab: $CUR — актуально" \
                        || echo "скиллы nlab: установлено ${CUR:-не установлен}, в реестре $REG — нужно обновление"
    date +%F > "$STAMP"
  else
    echo "скиллы nlab: реестр недоступен — работаем на локальной версии"
  fi
fi
```

`git fetch` только читает — клон реестра он не переключает и ничего в
проекте не меняет.

Что делать с результатом:

| Результат | Действие |
|---|---|
| версии совпали | молчать и работать дальше — не отвлекать пользователя |
| патч/минорная разница (4.9.0 → 4.9.1, 4.9.0 → 4.10.0) | одной строкой сказать: «скиллы отстали, обновитесь: `/plugin marketplace update nlab-vibeskills`» — и продолжить работу |
| мажорная разница (4.x → 5.x) | сообщить, что возможны ломающие изменения, и **дождаться** решения пользователя, прежде чем работать по новым правилам |
| реестр недоступен (нет сети, нет доступа к репозиторию) | работать на локальной версии, отметить в `project-docs/EVIDENCE.md`: «проверка обновления не выполнена»; работу не блокировать |
| после обновления версия не изменилась | предложить переустановку: `/plugin install nlab@nlab-vibeskills` |

Команды со слэшем набирает пользователь в своём окне — сам ты их выполнить
не можешь, не пытайся сделать это через Bash.
