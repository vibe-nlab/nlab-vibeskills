# Инструменты агента (tools)

> Часть спецификации (`spec/SPEC.md` §3). Для каждого инструмента —
> контракт, внешние системы и обратимость. Обратимость определяет уровень
> автономии (AGENTS.md §5): необратимое действие не может быть R4.
>
> Инструменты — типизированные, через pydantic-ai. Инструмент, который не
> описан здесь, в код не попадает.

## Список

| Инструмент | Назначение | Вход → Выход | Внешние системы | Обратимость | Автономия |
|---|---|---|---|---|---|
| | | | | обратимо / необратимо | R0–R5 |

## Контракты

### `<имя_инструмента>`

- **Зачем:** одна фраза на языке домена, не на языке реализации.
- **Вход / выход:** модели из [`schemas.md`](schemas.md).
- **Внешние системы:** что трогает; что будет, если система недоступна.
- **Обратимость:** обратимо / необратимо, и почему.
- **Ошибки:** что возвращает при отказе — конкретно, а не «исключение».
- **Ограничения:** таймаут, лимит вызовов, размер входа.

```python
@agent.tool
async def example(ctx: RunContext[Deps], arg: ExampleIn) -> ExampleOut:
    """Docstring уходит в промпт агента — пиши его как описание для LLM."""
```

## Чего инструменты делать не должны

Список запретов, вытекающих из границ автономии и из раздела «что не
входит» в `SPEC.md`. Например: не удалять пользовательские данные, не
писать в прод-таблицы, не ходить в интернет без явного инструмента.
