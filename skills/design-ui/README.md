# /nlab:design-ui — дизайн-система NeuroLab для shadcn-интерфейсов

Скилл для Claude Code: фирменные конвенции NeuroLab поверх shadcn/ui.
Сборку UI делает **оригинальный скилл `shadcn`** — он обязательная
зависимость и ставится отдельно (см. Установку); чат и AI-специфичные
экраны берутся из реестра **AI Elements**; этот скилл применяет поверх
фирменные правки.

Что даёт:

- UI строится оригинальным shadcn-скиллом по его правилам композиции
  (семантические токены, `Field`/`FieldGroup` для форм, готовые компоненты
  вместо самодельной разметки) — один источник правды, без расходящейся
  копии внутри;
- чат с AI, агентские интерфейсы, вывод рассуждений и вызовов инструментов —
  на [AI Elements](https://elements.ai-sdk.dev/docs) (реестр Vercel поверх
  того же shadcn), а не самописной лентой сообщений; фирменная тема ложится
  на них без правок;
- пользователю всегда выдаются обе ссылки —
  [ui.shadcn.com](https://ui.shadcn.com/docs/components) и
  [elements.ai-sdk.dev](https://elements.ai-sdk.dev/docs), — чтобы он сам
  выбрал компоненты, а не получил выбор агента;
- шрифт **Montserrat** самохостом (кириллица из коробки) на базовых 16px
  (root не масштабируется) в обеих темах;
- тёмная тема — фирменный тёплый графит `#272726` с выверенными ступенями
  нейтралей и проверенным WCAG-контрастом вместо дефолтного shadcn-чёрного;
- светлая тема остаётся стандартной (только шрифт и размер).

## Установка

Скилл входит в плагин `nlab` — ставится вместе со всем пакетом, отдельно
копировать ничего не нужно. См. [README реестра](../../README.md).

Отдельно нужна **обязательная зависимость — оригинальный скилл `shadcn`**
(`depends_on: [shadcn]`), официальный скилл shadcn/ui для Claude Code.
Если он уже установлен — шаг пропустить. Без него `/nlab:design-ui`
останавливается на проверке входов.

Необязательная зависимость — скилл `ai-elements` (локальные справочники по
компонентам AI Elements). Без него чат тоже соберётся: компоненты ставятся
CLI (`npx ai-elements@latest add ...`) по докам
<https://elements.ai-sdk.dev/docs>, просто без подсказок под рукой.

## Использование

1. Откройте Claude Code в проекте (существующем shadcn-проекте или пустой
   папке — скилл умеет и `init`).
2. Наберите `/nlab:design-ui` и опишите, какой интерфейс нужен.
3. Claude пришлёт ссылки на каталоги компонентов (shadcn/ui и AI Elements)
   и спросит, что берём.
4. Затем проверит, что скилл `shadcn` установлен, соберёт UI по его
   правилам (чат — на AI Elements), применит правки NeuroLab и прогонит
   чеклист (контраст, кириллица в Montserrat, отсутствие внешних запросов
   за шрифтами), зафиксировав результаты в `EVIDENCE.md`.

## Состав

| Файл | Назначение |
|---|---|
| `SKILL.md` | весь скилл: метаданные, входы/выходы, конвенции NeuroLab (шрифт, графитовая тема), enforcement-проверки, процесс |

Workflow shadcn (project context, CLI, поиск/установка компонентов,
правила композиции) намеренно **не** входит в состав — он живёт в
оригинальном скилле `shadcn` и обновляется его автором.

## Версии

- **1.4.0** — второй источник компонентов: AI Elements
  (<https://elements.ai-sdk.dev/docs>) для чатов с AI и агентских экранов;
  правило всегда давать пользователю ссылки на оба каталога, чтобы он выбирал
  компоненты сам.
- **1.3.0** — базовый размер шрифта 16px: правило `root 112.5% → 18px`
  отменено, root больше не масштабируется (масштаб тянул за текстом сетку
  и отступы — интерфейс выглядел «зумленным»).
- **1.0.0** — первая версия в составе плагина `nlab`.

До переезда в плагин скилл назывался `nlab-design` и существовал в двух
вариантах: самодостаточном (со встроенной копией shadcn-документации) и
текущем, который опирается на оригинальный скилл `shadcn`. Отсчёт версий
начат заново — прежние номера не имеют отношения к пакету.

Не путать с `/nlab:code-design` — тот отвечает за спецификацию и архитектуру
кода, этот только за внешний вид интерфейса.
