## 10. Авто-обновление

Проверять версию в `registry_url` согласно `update_check`:

- **`per_session`** (по умолчанию) — один раз при первом использовании
  скилла в сессии, не на каждый вызов.
- **`pre_deploy`** — перед каждым необратимым действием (используй для
  Deploy-скиллов и других enforcement-тяжёлых скиллов).
- **`manual`** — только по явному запросу пользователя (для скиллов без
  сетевого доступа к реестру или в изолированных контурах).

Поведение по результату проверки:

| Разница версий | Действие |
|---|---|
| Совпадает | Ничего не делать, работать дальше |
| Патч/минорная | Подтянуть автоматически + одна строка уведомления пользователю |
| Мажорная | Не обновлять автоматически, спросить подтверждение — возможны ломающие изменения |
| Реестр недоступен | Работать на локальной версии, отметить в `EVIDENCE.md`: "проверка обновления не выполнена" |

Это guidance-механизм: недоступность реестра не должна блокировать работу
скилла как таковую (в отличие от правил из п.5 Enforcement).
