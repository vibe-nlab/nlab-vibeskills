# /nlab-design — дизайн-система NeuroLab для shadcn-интерфейсов

Скилл для Claude Code: фирменные конвенции NeuroLab поверх shadcn/ui.
Сборку UI делает **оригинальный скилл `shadcn`** — он обязательная
зависимость и ставится отдельно (см. Установку); этот скилл применяет
поверх фирменные правки.

Что даёт:

- UI строится оригинальным shadcn-скиллом по его правилам композиции
  (семантические токены, `Field`/`FieldGroup` для форм, готовые компоненты
  вместо самодельной разметки) — один источник правды, без расходящейся
  копии внутри;
- шрифт **Montserrat** самохостом (кириллица из коробки) и укрупнённый
  размер (root 112.5% → 18px) в обеих темах;
- тёмная тема — фирменный тёплый графит `#272726` с выверенными ступенями
  нейтралей и проверенным WCAG-контрастом вместо дефолтного shadcn-чёрного;
- светлая тема остаётся стандартной (только шрифт и размер).

## Установка

1. **Поставьте оригинальный скилл `shadcn`** (обязательная зависимость,
   `depends_on: [shadcn]`) — официальный скилл shadcn/ui для Claude Code —
   в `~/.claude/skills/shadcn`. Если он уже установлен (есть
   `~/.claude/skills/shadcn/SKILL.md`) — шаг пропустить. Без него
   `/nlab-design` останавливается на проверке входов.

2. Скопируйте папку целиком в скиллы Claude Code:

   ```bash
   cp -r nlab-design ~/.claude/skills/nlab-design
   ```

3. Добавьте в `~/.claude/CLAUDE.md` (создайте файл, если его нет):

   ```markdown
   # nlab-design
   - **nlab-design** (`~/.claude/skills/nlab-design/SKILL.md`) — построить
     shadcn-интерфейс (оригинальным скиллом shadcn) и применить
     дизайн-систему NeuroLab (Montserrat + 112.5%, графитовая тёмная тема).
     Trigger: `/nlab-design`
   When the user types `/nlab-design`, invoke the Skill tool with
   `skill: "nlab-design"` before doing anything else.
   ```

## Использование

1. Откройте Claude Code в проекте (существующем shadcn-проекте или пустой
   папке — скилл умеет и `init`).
2. Наберите `/nlab-design` и опишите, какой интерфейс нужен.
3. Claude проверит, что скилл `shadcn` установлен, соберёт UI по его
   правилам, применит правки NeuroLab и прогонит чеклист (контраст,
   кириллица в Montserrat, отсутствие внешних запросов за шрифтами),
   зафиксировав результаты в `EVIDENCE.md`.

## Состав

| Файл | Назначение |
|---|---|
| `SKILL.md` | весь скилл: метаданные, входы/выходы, конвенции NeuroLab (шрифт, графитовая тема), enforcement-проверки, процесс |

Workflow shadcn (project context, CLI, поиск/установка компонентов,
правила композиции) намеренно **не** входит в состав — он живёт в
оригинальном скилле `shadcn` и обновляется его автором.
